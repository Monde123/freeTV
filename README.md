# Free-TV IPTV (React + Vite)

Une interface web moderne et performante pour accéder aux listes de lecture IPTV gratuites et officielles du monde entier.

## ✨ Caractéristiques
- **Propulsé par React & Vite** : Performance optimale et développement moderne.
- **Sync iptv-org** : Câblé directement sur les sources officielles de [iptv-org/iptv](https://github.com/iptv-org/iptv).
- **SEO Optimisé** : Meta-tags dynamiques, structure sémantique et performance Lighthouse élevée.
- **Responsive Design** : Compatible mobile, tablette et desktop.
- **Animations Fluides** : Interface interactive avec Framer Motion.

## 🚀 Installation locale

1. Clonez le dépôt :
```bash
git clone <votre-url-depot>
cd freetv-site
```

2. Installez les dépendances :
```bash
npm install
```

3. Lancez le serveur de développement :
```bash
npm run dev
```

4. Construisez pour la production :
```bash
npm run build
```

## 📡 Sources des liens
Tous les liens M3U8 sont récupérés en temps réel depuis le dépôt communautaire [iptv-org](https://github.com/iptv-org/iptv). Ce projet est une interface de visualisation et ne possède aucun flux.
